
# 📘 01 — Data Basics

This section introduces the foundational concepts of data literacy.  
Before learning about data warehouses, Hadoop, data lakes, or lakehouses, it is essential to understand **what data is**, **how it is classified**, and **how systems process it**.

These fundamentals form the base for all modern data architectures.

---

## 📂 Files in This Folder

### 1. `what_is_data.md`
Explains:
- The definition of data  
- Types of information (facts, observations, events)  
- How data is generated in real systems  
- Why data became the core asset of modern organizations  

### 2. `structured_vs_unstructured.md`
Covers:
- Structured data (tables, rows, columns)  
- Semi‑structured data (JSON, XML, logs)  
- Unstructured data (images, audio, video, text)  
- Why different data types require different storage and processing systems  

### 3. `oltp_vs_olap.md`
Describes:
- OLTP (Online Transaction Processing)  
- OLAP (Online Analytical Processing)  
- Differences in workload, design, and purpose  
- Why OLTP databases cannot handle large‑scale analytics  
- How OLAP led to the creation of data warehouses  

---

## 🎯 Purpose of This Module

By completing this section, you will understand:

- What data actually is  
- How data is categorized  
- Why structured vs unstructured matters  
- Why OLTP and OLAP systems exist  
- Why analytics required new architectures beyond traditional databases  

These fundamentals prepare you for the next modules on:
- Evolution of data systems  
- Data warehouses  
- Big data  
- Hadoop  
- Data lakes
